# 💳 Cartão de Crédito Animado
Este projeto foi desenvolvido para praticar HTML e CSS, criando um cartão de crédito interativo com animações e efeitos visuais.

## 🛠️ Tecnologias utilizadas
- HTML  
- CSS  

## 🎯 Objetivo
Praticar a criação de animações e interações visuais usando apenas HTML e CSS, desenvolvendo um cartão de crédito virtual estilizado e funcional.

## 🌐 Visualizar projeto
(https://liadaine.github.io/cartao-credito-animado/)

## 📚 O que foi praticado
- Estruturação do cartão em HTML  
- Estilização com CSS (cores, gradientes e efeitos de hover)  
- Animação da frente e verso do cartão  
- Alinhamento e organização de elementos para criar um layout visualmente agradável
